# RailSwap 🚆

RailSwap is a web-based platform that allows passengers travelling on the same train journey to connect with each other for seat and berth swapping.

## Project Objective

RailSwap allows passengers to:

- Join a specific train journey
- Enter their seat and berth details
- View other participating passengers on the same journey
- Find compatible seat-swapping opportunities
- Send seat swap requests
- Accept or reject swap requests
